Running in development Running as a built application

Hello from

A wonder-slim application with as little as possible: five files and one dependency.

What just happened

  1. Application.main() started the application through ERXApplication.
  2. It found build.properties in the working directory, so it's running from its project folder: development mode, with NSProjectBundleEnabled set. A built application runs from inside its .woa, where there's no build.properties.
  3. ERProjectLayout read build.properties, saw a project (it has project.name and project.type), and found this component in src/main/components, the standard place, since build.properties doesn't say otherwise.
  4. Your browser asked for /, which Application maps to Main.
  5. Main rendered this template, Main.wo/Main.html. The name above comes from an inline binding, <wo:str value="$application.name" />, and the badge from a <wo:if> on $application.isDevelopmentMode.

The whole project

pom.xml One dependency, ERExtensions, which brings WebObjects along. vermilingua builds the .woa.
build.properties What the project is: its name, that it's an application, and its principal class.
Application.java Starts the application and maps / to Main.
Main.java The component behind this page. It doesn't need to do anything.
Main.wo/Main.html This page.

No IDE required

There are no Eclipse files in the project: nothing reads .project, .classpath or .settings. Any IDE that runs main() with the Maven classpath, from the project folder, runs it in development, and mvn package builds a .woa to deploy.
